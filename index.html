Home Assistant (personal)

This is a private, single-household Home Assistant installation. It uses Google's Smart Device Management API so the owner's own Google Nest devices (doorbell and cameras) can be viewed and automated from their home server.

It is not a public product or service. The only user is the owner, and no one else can sign in or use it.

See the privacy policy and terms of service.
